# 音素 xMusic

一款专为手机与车机打造的 Flutter 音乐播放器，聚合 QQ 音乐歌单/电台/榜单与自建 NAS（Navidrome/Subsonic）音乐库，支持封面透出背景、睡前渐弱、均衡器等个性化体验。

## 功能

### 首页
- **QQ 电台**：按分组浏览个性电台、曲风电台，点进即播
- **QQ 歌单广场**：按风格分类（流行/摇滚/民谣/电子/爵士/R&B/古风/纯音乐/古典等）浏览精选歌单
- **QQ 榜单**：飙升榜、热歌榜等实时榜单

### 音乐库
- **NAS 歌单**：对接 Navidrome/Subsonic，浏览你的歌单、专辑、歌手
- **ID 歌单**：粘贴 QQ 歌单 ID 即可导入本地管理，支持重命名/删除，封面自动拉取
- **本地**：本地音乐文件浏览播放
- **收藏**：收藏歌曲一键回看
- **歌手**：按歌手浏览专辑

### 播放
- 竖屏：封面 + 歌词同步滚动，左右分列快捷按钮
- 横屏（车机）：自动适配横屏布局，miniplayer 抬高避开系统导航栏
- 播放路径显示：当前歌曲来自哪个歌单/榜单，左上角一目了然
- 播放队列：透明背景、可滑动查看完整歌名/歌手
- 下载：单曲下载到本地 / 下载到 NAS；整个歌单一键批量下载（外层自动建歌单文件夹）
- 黑名单：左滑拉黑不想听的歌，自动同步到 NAS
- 相似歌曲 / 相关歌单推荐（待开发）

### 个性化
- **主题模式**：浅色 / 深色 / 跟随系统
- **封面透出背景**：全局跟随当前歌曲封面模糊染色，所有界面统一
- **自定义背景**：可手动选择背景图
- **歌词**：字号、颜色自定义，调整后自动保存
- **睡前模式**：10~90 分钟自由设定，从一半时间开始线性渐弱音量，到点自动停止（渐弱可单独开关）

### 车机适配
- 自动识别车机横屏（shortestSide ≥ 480dp）
- 横屏减小播放控制栏尺寸，miniplayer 抬高避开系统导航条
- 车机端自动隐藏下载按钮与 EQ
- MediaSession 常驻，支持方向盘控制

## 技术栈

- Flutter + Dart
- just_audio / audio_service（音频播放 + 后台通知控制）
- cached_network_image（封面缓存）
- scrollable_positioned_list（歌词滚动）
- QQ 音乐匿名 API + Navidrome/Subsonic API + WebDAV

## 首次配置

首次启动可先进入首页浏览；在设置中配置 Navidrome 地址与账号后解锁完整功能：

1. **设置 → 个性化**：配置 NAS（Navidrome）地址、用户名、密码
2. **设置 → 主题**：选择主题模式、封面透出背景开关、歌词大小/颜色
3. **设置 → 同步**：开启 WebDAV 同步黑名单与 ID 歌单
